# A股股票分析顾问

输入股票代码或名称，基于四个维度给出综合评分和买卖建议。

## 功能

- **技术面** (25%) — MA/MACD/RSI/KDJ/BOLL 综合趋势判断
- **资金面** (25%) — 主力资金流向、大单主导度、持续性分析
- **情绪面** (25%) — 市场涨跌比、量比、换手率等替代指标
- **基本面** (25%) — PE/PB估值、ROE盈利、营收/利润增长、资产负债率

## 数据来源

- 实时行情：雪球
- K线历史 + 资金流向 + 财务指标：东方财富
- 市场概况：新浪

全部免费，无需 API Key。

## 运行

```bash
pip install -r requirements.txt
streamlit run app.py
```
